Dựa vào cấu trúc thư mục và các tệp tin trong không gian làm việc của bạn, đây là phần tóm tắt toàn bộ project **BTL_SPMeVaBe** (Bài tập lớn - Sản phẩm Mẹ và Bé):

### 1. Tổng quan dự án
Đây là một ứng dụng Web Thương mại điện tử chuyên bán các sản phẩm dành cho mẹ và bé. Project được xây dựng hoàn toàn theo mô hình **MVC (Model - View - Controller)** truyền thống trong Java Web.

### 2. Các công nghệ sử dụng
*   **Ngôn ngữ lập trình:** Java.
*   **Backend framework/công nghệ:** Java Servlet, JSP (JavaServer Pages).
*   **Frontend:** HTML, CSS (thư mục css), JSP. 
*   **Cơ sở dữ liệu:** CSDL Quan hệ (SQL), kết nối thông qua JDBC (thể hiện qua class `DBConnect.java` và file `create_tables.sql`). Môi trường quen thuộc có thể là MySQL hoặc SQL Server.
*   **Công cụ Build/IDE:** Sử dụng Apache Ant (build.xml) và dựa trên cấu trúc thư mục, IDE được sử dụng là **NetBeans** (nbproject).
*   **Web Server:** Ứng dụng thường được chạy trên Apache Tomcat hoặc GlassFish.

### 3. Tính năng chính
Dự án được chia làm 2 phân hệ rõ rệt:

**A. Phân hệ Người dùng/Khách hàng (Client):**
*   **Xác thực:** Đăng ký, Đăng nhập, Đăng xuất (`LoginServlet`, `RegisterServlet`).
*   **Sản phẩm:** Hiển thị danh sách sản phẩm, Xem chi tiết sản phẩm, Để lại đánh giá/nhận xét dười mỗi sản phẩm (`HienThiSP.java`, `ProductDetailServlet`, `ReviewServlet`).
*   **Giỏ hàng & Thanh toán:** Thêm/sửa/xóa sản phẩm trong giỏ hàng (`CartServlet`), Thực hiện Thanh toán (`CheckoutServlet`), Nhập địa chỉ nhận hàng.
*   **Quản lý cá nhân:** Xem lịch sử mua hàng, chi tiết các đơn hàng đã đặt (`OrderHistoryServlet`).

**B. Phân hệ Quản trị (Admin):**
Được bảo vệ bảo mật bởi bộ lọc `AdminFilter.java`. Phân hệ này dùng để nhân viên/quản trị viên thao tác:
*   **Quản lý người dùng:** Quản lý tài khoản, khách hàng (`AdminUserServlet`, `admin/users.jsp`).
*   **Quản lý sản phẩm:** Thêm, sửa, xóa thông tin sản phẩm (`AdminProductServlet`, `admin/products.jsp`).
*   **Quản lý đơn hàng:** Xem danh sách đơn giao dịch, duyệt đơn hoặc cập nhật trạng thái đơn hàng (`AdminOrderServlet`, `admin/orders.jsp`).

### 4. Lưu trữ dữ liệu (Data Storage)
Cơ sở dữ liệu được thiết kế tập trung với các thực thể (Entity) tương ứng trong thư mục `Model`. Dữ liệu sẽ lưu trữ ở CSDL (SQL) bao gồm các bảng tương ứng với các object sau:
*   `NguoiDung` (cơ sở), `KhachHang`, `NhanVien`, `Person`: Thông tin về các loại người dùng và phân quyền.
*   `SanPham`: Thông tin các mặt hàng (tên, giá, mô tả, ảnh, tồn kho...).
*   `DonHang`, `ChiTietDonHang`: Lưu thông tin của 1 đơn thanh toán và các mặt hàng bên trong đơn đó.
*   `DiaChiNhanHang`: Lưu địa chỉ ship hàng của khách hàng.
*   `DanhGia`: Lưu phản hồi, đánh giá cho sản phẩm.
*   *Quy trình tương tác DB:* Thông qua các pattern lập trình Data Access Object (DAO) (ví dụ: `SanPhamDAO`, `KhachHangDAO`), đây là các class chứa các câu lệnh SQL tĩnh để `SELECT`, `INSERT`, `UPDATE`, `DELETE` thông qua Connection `DBConnect`.

### 5. Luồng dữ liệu hoạt động (Data Flow - Mô hình MVC)
1.  **View (Giao diện):** Người dùng thao tác trên trình duyệt với các trang `.jsp`. Ví dụ: Bấm nút "Thêm vào giỏ" trên trang `product-detail.jsp`.
2.  **Controller (Điều khiển):** Yêu cầu (Request) HTTP gửi về Server. Các class Java trong Controller (Servlet) bắt được yêu cầu tương ứng (VD `CartServlet`).
3.  **Model (Xử lý nghiệp vụ & Data):** Controller sẽ nhận `parameter` từ request, sau đó gọi xuống các lớp **DAO** tương ứng. 
4.  **Database (Truy xuất):** Lớp DAO sẽ dùng `DBConnect` để chọc xuống Database, lấy lên kết quả, đóng gói vào các class trong lớp **Model** (VD trả về đối tượng `SanPham` hoặc `CartItem`).
5.  **Render View (Phản hồi):** Controller nhận Data (dạng Object Model) từ DAO, lưu vào biến request hoặc session (`request.setAttribute`), sau đó `forward` hoặc `redirect` trở lại đích View mới (VD `cart.jsp`).
6.  Trang `cart.jsp` đọc dữ liệu trả về và render đoạn HTML cho trình duyệt người dùng hiển thị.
